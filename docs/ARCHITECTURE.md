# 架构与业务规则

浏览器 → Nginx `/fabricworld/` → Go `127.0.0.1:18082` → 独立 SQLite 与图片文件。Vue 3/TypeScript/Vite 前端内嵌在 Go 程序；服务器使用 libvips 命令行处理图片，无 Node 常驻应用。

## 布料与余料

一条记录表示一批布料。材质/标签为去重字符串数组，地点为文本；不存在用户、身份或个人库。宽、长允许未知，以 cm/m 输入并转换为整数 mm，片数 1–999，每条最多 50 组。未知不等于 0。不规则余料记录最大宽长和备注，尺寸筛选只匹配完整矩形。购买总价以整数分解析，不随余料减少。

材质名称继续用于筛选，百分比独立存储在 materialPercentages 映射，不写进名称或成分说明。单选默认 100%；从单选增加为两项时，清空单选默认值，两项比例均留空；继续增加第三项时保留已经填写的比例。多选时，每项前方提供可留空的小输入框，原样保存十进制字符串，不校验总和、不自动配平或舍入。取消选中移除对应比例，剩下一项时恢复 100%。旧记录的多选比例保持未知；说明文本不自动解析。详情、列表、历史、复制及导出均保留比例；更新余料不修改比例。

材质管理从当前布料记录提取名称和使用数量，包含已用完和回收站记录；同一布料对同名材质只计一次，回收站数量另列。material_catalog 保存从管理页面独立添加的名称与随机身份，允许零使用；目录合并该表与当前布料中出现的名称，数量始终从布料实时计算。未使用且未独立添加的内置选项不列入管理。编辑器同时提供内置选项、目录中已添加的名称、已保存的自定义材质和当前选中项。移除按名称精确匹配，一次从全部相关布料及百分比映射中删除；剩下一种材质恢复 100%，多种保留各自原比例。布料、照片、成分说明和其他资料不变，历史快照保留。仅由布料使用产生的名称在失去最后一次使用后退出列表；独立添加的名称保留到明确移除。移除同时删除目录条目；内置选项仍可重新选择。

状态为 unused/using/used。在库状态至少有一组布片，used 不得有布片。详情页“编辑资料”负责照片、材质等资料，尺寸与状态修正默认折叠；普通编辑不自动改变状态。

“更新余料”位于详情的剩余尺寸旁，进入独立 `/fabrics/:id/remnant` 页面，仅填写剩余布片或选择“已经用完”。保存余料转为 using，用完需再次确认并清空当前布片；切换选项或取消确认保留未提交的尺寸。已用完记录隐藏余料入口，录入错误可在编辑资料中修正状态。服务端 remnant 动作只更新 pieces/status，保留所有资料与图片引用，并保留 revision、幂等和修改历史校验。旧 `edit?mode=remnant` 链接跳转至新页面；旧客户端提交完整表单时，余料动作忽略其他字段。

复制只带名称、材质、成分、颜色、标签、地点与备注，不复制图片、尺寸或购买信息。

列表默认在库、最近购买日期优先，缺失时取录入日期，每页 24 条。查询在服务端完成，包含匹配名称/材质/标签/成分/备注/店铺/地点；材质/颜色/地点/标签精确筛选；尺寸必须由同一布片满足。计数覆盖完整筛选集，概览统计整个未删除库。

## SQLite 与写入

schema v1，application_id 1178681932；WAL、外键、FULL 同步、5 秒 busy timeout、单连接。fabrics 将有界业务 JSON 与检索列存储在一起；嵌套布片保存在 JSON 中，使用 JSON1 查询。media 独立维护文件引用；changes 记录每次修改前后业务快照；operations 保存幂等结果。

所有布料写入检查 revision，在同一事务中更新布料、照片归属、修改历史和幂等结果。相同幂等键与请求指纹返回之前结果；不同请求复用键返回 409。图片处理不占写事务；图片上传也有按内容摘要核对的幂等结果。普通操作记录保留 7 天；不对过期未知结果自动重试。

批量移除材质使用目录随机身份（如有）及相关布料的有序 ID/revision 集合摘要作为 version。提交时重新核对，相关记录新增、修改、删除或恢复后返回 409，要求刷新并重新确认。所有相关记录的 revision、更新时间、remove_material 历史及幂等结果在一个事务提交，失败整体回滚，不改照片归属。添加与移除均先查询原操作结果，避免旧添加重试重新创建已移除的名称，或旧移除重试误删后来重新添加的材质。名称唯一约束使并发重复添加只保留一个条目；重新添加生成新的随机身份，过期的零使用移除请求也会冲突。

Ledger 联动由独立 /api/integrations/ledger 接口接收交易 ID、标题、日期和总价。将 ledger:<UUID> 的 SHA-256 前 16 字节作为稳定操作键，指纹使用同一来源串；来源去重与布料创建在同一事务提交。此类 operations 不按 7 天清理，随数据库备份恢复；即使布料已编辑或删除，重试也不新增或覆盖。返回前读取当前布料，删除时提示核对/恢复。Ledger 联动不改变 schema。布料名称上限 500 字符，与 Ledger 标题一致。

服务启动要求现有数据库身份/schema/完整性正确。首次安装明确 init，缺失或损坏不能自动建空库。独立材质目录通过显式 migrate 命令新增兼容表；保留 user_version=1 和既有记录格式，旧程序可读取扩展后的数据库。check/serve 要求目录表存在，缺表时提示先备份再 migrate，不在启动中隐式建表。首次 init 直接包含目录表，备份覆盖整个数据库；旧备份 restore 后可显式 migrate 再 check。

## 图片生命周期

文件最多 25 MiB、80 MP，每条最多 10 张；校验内容签名，接受 JPEG/PNG/WebP/HEIC/HEIF。拒绝 SVG 与动态 PNG/WebP。HEIC 由 libheif 选择主图。libvips 自动归正方向、输出 sRGB、最长边 2560 px 的 JPEG（Q88）与 640 px WebP 缩略图（Q80），移除元数据。原始上传仅临时保留。

图片逐张流式落盘，全局一个处理槽，繁忙返回 429；解码流程 40 秒超时。生成文件采用随机 ID，写入完整且同步落盘后才能提交 media 行；正式文件不可变。暂存 24 小时内可绑定，不能绑定到两条布料。照片移除保留 30 天，布料删除进入 30 天回收站。维护任务删除过期引用，并回收至少 24 小时的孤立文件/临时目录。

备份和清理使用跨进程 flock。上传/ZIP 导出持共享锁，备份/清理持独占锁，繁忙返回明确提示。备份使用 VACUUM INTO 一致性快照，枚举该快照图片并做硬链接与 SHA-256 清单；图片不可变保证同盘硬链接稳定。备份可能使新上传短暂返回繁忙，普通记录读写仍可进行。备份包含尚未过期的暂存、移除图片与回收站引用。

初始媒体配额 5 GiB，根盘可用不足 5 GiB 拒绝上传。应用 systemd 总内存上限 640 MiB，CPUQuota 100%，图片线程 1。配额含 media 表内暂存与移除文件；实际磁盘与备份保留还需运维 df/du 检查，不能把配额当整盘隔离。每 IP 每分钟写入 120 次，上传单独 30 次；只有来自 loopback 的代理可提供 X-Real-IP。

## 浏览器

页头右侧仅保留三横线菜单，展开后进入回收站或 /materials 材质管理；点击品牌返回布料库。菜单支持点击外部、焦点离开、路由变化和 Escape 关闭，方向下键可展开并聚焦首项。材质管理提供搜索、使用数量和移除确认；搜索非空且无结果时显示添加按钮，直接添加独立材质，零使用名称也能再次移除。添加和移除提交结果不明时保存原请求及幂等键到 sessionStorage，可查询或按原键重试，刷新页面优先恢复操作结果。版本冲突会刷新列表并要求重新选择。

材质百分比、幅宽、长度与购买总价使用 type=text、inputmode=decimal、autocomplete=off，向手机请求带小数点的数字键盘，保留字符串输入精度。片数仍使用整数数字键盘。实际键盘布局由系统和输入法决定，桌面 WebKit 移动视口不能验证真机键盘。

购买日期保留原生 date 控件；边框、内边距与焦点样式放在外层 date-input，内部 input 使用零边框、零内边距，避免 [WebKit 301648](https://bugs.webkit.org/show_bug.cgi?id=301648) 在 iOS 上把 padding 加到 100% 宽度。手机端日期与总价分别占一行，桌面并排。仅设置 max-width 或改为单列不能解决这个原生控件问题。

网站使用森林绿底的布卷与织纹图标，页头与浏览器 SVG 图标共用 `web/public/fabricworld.svg`；ICO 提供 16/32/48 px，Apple Touch 图标为 180 px。修改 SVG 后运行 `npm --prefix web run icons`（使用现有 libvips）重新生成两份位图；资源路径使用 Vite BASE_URL，支持子路径及详情页刷新。

拍照 input 使用 capture=environment，相册多选分开。摄像头选择由手机系统决定；HTTP 下不使用 getUserMedia、Service Worker 或离线同步。上传以 XHR 显示进度，失败逐张重试；图片未完成需重试/移除后才能保存。

记录新布料和编辑资料时，点击照片可打开大图预览，使用与详情页相同的 Modal 组件。已上传照片读取标准主图，待上传或上传失败的照片使用本地 object URL；上传完成后，正在预览的本地图片先切换到服务器主图，再释放 object URL。浏览器无法解码的本地格式显示提示，上传完成后可查看转换后的图片。预览不提交表单；关闭按钮、遮罩或 Escape 关闭后保留输入内容，移除、排序和上传重试仍由独立按钮操作。

文字与成功上传引用存于 sessionStorage，24 小时内可恢复；编辑草稿必须与服务端 revision 一致。刷新后未上传 File 无法恢复。保存成功才清除草稿；未知写入先查 operations，相同内容可用原键重试。界面用纯文本输出用户数据；来源检查、CSP、nosniff、请求上限降低跨站和文件风险，但不是身份鉴权。

余料页草稿单独存储，不与资料编辑草稿混用；保存前记录原幂等键，刷新发现未确认写入时先查询操作结果，即使服务端 revision 已更新也不会先丢弃这次提交。确定未提交的旧版本草稿不覆盖新版本尺寸。

CSV 防公式注入。ZIP 流式导出当前筛选下的记录和标准主图，默认在库，可包含已用完；不包含回收站。导出不是数据库恢复格式，没有网页导入。
